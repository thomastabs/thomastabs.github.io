## Os títulos constroem o índice

Cada título `##` e `###` passa a ser uma entrada do índice. Em ecrãs largos fica na margem direita e acompanha a leitura. Em ecrãs estreitos dobra-se num bloco que abre e fecha, acima do texto.

### Um título de terceiro nível

Os títulos de terceiro nível aparecem recuados no índice.

## Blocos de código

O código é realçado na compilação com o Shiki, com um tema para o papel e outro para a mesa de desenho. Cada bloco tem um botão de copiar.

```ts
/** Tempo de leitura em minutos, a cerca de 220 palavras por minuto. */
export function readingMinutes(body = ''): number {
  const words = body.split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(words / 220));
}
```

Código em linha, como `seriesOrder`, usa a letra monoespaçada.
