This entry exists to show how a Notebook post renders. It is marked `draft: true`, so it appears in `astro dev` with a red stamp and is left out of production builds, feeds, listings and the sitemap.

## Headings build the contents

Every `##` and `###` heading becomes an entry in the table of contents. On wide screens it sits in the right margin and follows your scroll position. On narrow screens it folds into a collapsible block above the text.

### A third-level heading

Third-level headings are indented one step in the contents.

## Code blocks

Code is highlighted at build time with Shiki, with one theme for paper and one for the drafting table. Each block gets a copy button.

```ts
/** Reading time in minutes, at about 220 words per minute. */
export function readingMinutes(body = ''): number {
  const words = body.split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(words / 220));
}
```

Inline code such as `seriesOrder` uses the mono face.

## Footnotes

Footnotes are written in Markdown[^1] and collected at the end of the post, each with a link back to where it was cited.[^2]

[^1]: GitHub-flavoured Markdown syntax: `[^1]` in the text, `[^1]: …` for the note.
[^2]: The back-link label is translated on Portuguese posts.
